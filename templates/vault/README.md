# База знаний

Этот Obsidian vault используется Hermes Agent для сохранения знаний.

- `00 Inbox` — необработанные материалы.
- `10 Knowledge` — постоянные атомарные заметки.
- `20 Sources` — конспекты источников.
- `90 System/Templates` — шаблоны.

Файл `.hermes.md` задаёт правила, по которым агент создаёт и обновляет заметки.
